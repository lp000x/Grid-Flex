Align X Justify

Sempre é necessário usar essas propriedades para mudar o posicionamento dos itens, mas sempre existe confusão também, uma confusão maior ainda quando não se para e define com clareza qual faz o que.

Align-items Align-content

O "align", independente se for item ou conteúdo, é o alinhamento vertical.

Justify-items Justify-content

O "Justify", independente se é item ou conteúdo, é o alinhamento horizontal.

Items X Content

Itens são os items individualmente. No caso dessa tabela, é o A, B, C, D e etc. Content é o conjunto, como se todas as letras fossem 1 coisa só.

Apesar das diferenças, todos eles são aplicados no container (ou seja, em quem recebe o display grid).

Align-items

É muito fácil confundir esse tipo de coisa. Onde o align-items afeta? O que ele muda? O grid container tem vários quadradinhos (justamente, os gride itens, lembrando da anatomia da grid). O align-items não vai alterar o container, a grid. É 1 configuração que vai alterar todos os quadradinhos (os grid items) dentro do container. Dependendo da largura dos grid itens, não são quadradinhos, são reangulos o "quadradões", mas ainda assim são os grid itens, os mesmos que o aling-items altera.

Mais especifico ainda, essas alterações dizem respeito ao posicionamento. Não é o grid item em si que será alterado, mas o item que está dentro dele. O grid item é um espaço, assim como o container. Dentro do container tem os grid items, e dentro dos grid items tem os itens. É nos itens que o align-items atua.
