Lembrando: todas essas propriedades se aplicam apenas ao container. Se adicionar elas aos itens, não acontece nada.

Display: grid;

O display: grid torna um container uma grid. Automaticamente, ao definir esse display o container vira um grid e o que estive dentro dele grid items

Diferente do display: flex, nada muda de imediato, porém a tecnologia grid foi ativada. Para ter uma mudança visual, é preciso adicionar outras propriedades.

grid-template-columns: auto auto

Essa propriedade diz que a grid terá um template de 2 colunas

O valor "auto" diz respeito a largura das colunas, instruindo a usar um valor automático, mas eu posso definir valores diferentes.

Além disso, a quantidade de valores que eu colocar é a quantidade de colunas que serão criadas. Se eu colocar auto auto, somente 2 colunas serão criadas. Se eu colocar auto auto auto 3 colunas serão criadas, e assim por diante.
