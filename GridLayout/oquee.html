O Que É Grid Layout

CSS Grid Layout é um sistema para criação de layout baseado em uma grade bidimensional e otimizado para o design de interfaces de usuário.

Nesse modelo de grade, os elementos filhos do conteiner que define a grade podem ser posicionados livremente em espaços criados na estutura, quer ela tenha sido definida com suas dimensões flexiveis ou não.

Anatomia de um Grid

Todo grid tem como parte fundamental um container

Esses "quadradinhos" dentro do container, todos eles, são os grid itens

Quando existe uma linha que vai do começo da linha até o final, seja vertical ou horizontal (nesse caso, não há distinção, track se refere apenas a quando uma linha inteira "marca" a grid), ela recebe o nome de track

Linhas horizontais recebem o nome de row track, enquanto que as linhas verticais recebem o nome de column track

Uma grid também possui linhas verticais em sua anatomia, que se chama line grids. Elas começam na esquerda e se estendem para a direita, sempre recebendo um valor númerico

Tem também as linhas horizontais que formam a grid, que também recebem o nome de grid lines e também são numeradas em ordem, começando de cima e se estendendo para baixo.

As line grids, horizontais e verticais, possuem 2 valores ao mesmo tempo: positivos e negativos. Eles são inversos: se o primeiro número é 1, o ultimo da line grid é -1. Se o primeiro é 2, o penultimo é -2. Se o terceiro é 3, o antipenultimo é -3, e assim sucesivamente.

Se tratando agora dos itens, é possível adicionar um espaçamento entre cada item da grid. Esse espaço se chama grid gap
