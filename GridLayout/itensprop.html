Propiedades Para Itens

Relembrando: da mesma forma que as propriedades de container só funcionam em container, propriedades para itens só funcionam em itens.

Grid areas

Os grid areas me permitem criar espaços dentro de um container. Aqui a abordagem diferente: é como se eu deixasse de ver os grid-itens como lugares individuais onde vão cada elemento e visse toda a área quadriculada, onde posso desenhar qual espaço quero ocupar.

Como Definir Grid Areas

Para definir as áreas, eu vou precisar ter em mente a numeração das grid lines. Lembrando que eu posso ver elas usando o tools dev do google.

Outra coisa que vou precisar é das seguintes propriedades: grid-row e column-row

  • Grid-row-start: aqui eu vou definir em qual linha começa a caixa, usando a numeração das grid lines;
  • grid-row-end: vou definir onde termina a linha da caixa, também usando a numeração das grid lines;
  • grid-column-start: vou definir em qual coluna começa a caixa (usando a numeração)
  • grid-column-end: vou definir em qual coluna termina a caixa (também usando a numeração)

O que são essas 4 propriedades? Simples: elas demarcam o começo e fim. Grid-row (start e end) define em qual linha a área começa e qual linha termina (define a altura do elemento, digamos assim), grid-column define em qual coluna começa e qual termina a área coluna (ou seja, define a largura da área.). É como se eu estivesse desenhando um quadrado com determinada largura e altura através de coordenadas.

Para criar as 3 caixas, eu preciso criar 3 divs. Se quiser criar mais ou menos caixas, basta usar a quantidade respectiva de divs. Vou colocar uma classe nas divs para usar no css e configurar a área da caixa. No CSS, eu vou chamar as classes e usar os grid-row e grid-column para definir o tamanho delas.
