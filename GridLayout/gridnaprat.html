Shorthand para classes

Caso eu vá criar uma div já sabendo que vou colocar um id ou class nela, em vez de criar a div e digitar class="xxx", eu já posso criar direito escrevendo div.container. Automaticamente será criada uma div já com a classe container. E caso eu queira criar vários itens dentro dessa div container com a mesma classe, basta eu digitar div.item*7. Esse * vezes um número indica quantas divs serão criadas com a classe item.
